# 7-STAR
Display the complete Holy Quran.
- Include all 114 Surahs.
- Allow users to choose any Surah.
- Allow users to choose from a large collection of famous Quran reciters.
- Play Quran recitations with a simple audio player.
- Play, pause, resume, and stop audio.
- Skip to the next or previous Surah.
- Show the current Surah and reciter name.
- Allow users to search for Surahs and reciters.
- Add favorite Surahs and reciters.
- Remember the user's last listened Surah.
- Provide a clean and beautiful Arabic interface.
- Support Arabic text correctly from right to left.
- Include a dark mode.
- Make the application fast and mobile-friendly.
- Make the design suitable for Android phones.

## Home Screen

The home screen should contain:
- App name: 7-STAR
- A beautiful Quran-themed design.
- A button to open the Quran.
- A button to choose a reciter.
- A search button.
- Favorite section.
- Recently played section.

## Quran Screen

Show:
- Surah name
- Surah number
- Arabic Quran text
- Ayah numbers
- Audio player
- Play and pause buttons
- Next and previous Surah buttons

## Reciters

Create a reciters page where users can browse and select famous Quran reciters.

Each reciter should have:
- Name
- Available Surahs
- Play button

## Design

Use a modern, elegant Islamic design.
The application should be simple for children and adults to use.
Use readable Arabic fonts and a clean layout.
Make all buttons easy to understand.

## Important

Do not use copyrighted audio without permission.
Use a reliable and legally permitted Quran audio source/API.
Use accurate Quran text from a trusted source.
The application must work well on mobile devices.
